# Établi: design demo

Démo de conception de l’application Établi. Toutes les données sont inventées.

A clickable design demo of Établi, an Android app in the making for a heating and cooling technician, served at
<https://shellkah.github.io/etabli-demo/>. It is built elsewhere from a design canvas into this static site, and
nothing here is edited by hand.

- **Invented data.** Every name, address, phone number and e-mail address in it is made up. The phone numbers are in
  blocks ARCEP reserves for fiction, and the e-mail addresses are on example.com.
- **Not the app.** Nothing typed into it is kept, and its pages make no request outside the demo's origin.
- **This build:** `20261125T234106-77ab03ab`, from canvas version `1795640210-f3ad`.
- **Earlier builds:** `assets/` keeps their files, so a page opened before a publish can still load, then moves to
  the new build.
- **Licences:** the fonts' (SIL Open Font License) and Preact's (MIT) are in `LICENSES/`: `Barlow-OFL.txt`, `Barlow-Semi-Condensed-OFL.txt`, `Inter-OFL.txt`, `preact-LICENSE.txt`.
